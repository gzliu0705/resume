# 简历母版｜MASTER

**唯一通用简历内容母版：**[双页 TeX 源文件](working/WentworthLiu_General_DS.tex) · [双页 PDF](working/WentworthLiu_General_DS.pdf) · [内容说明与待核实事项](working/README.md)。这是本人指定的后续定制简历起点；当前目录中的旧通用版及一页版都不是母版。

## 从母版构造岗位简历

1. 先阅读[母版说明](working/README.md)和[证据索引](../../evidence/README.md)，按岗位从母版 TeX **复制**出独立源文件，再增删项目、调整重点；不要直接覆盖母版。
2. 在 `applications/<岗位>/source/` 维护定制 TeX，未投递的 PDF 放 `working/`；实际投递且经本人确认的 PDF 再按[岗位结构规则](../../applications/STRUCTURE.md)归入 `submitted/`。
3. 已投递 PDF 是当时版本的归档，不随母版更新而覆盖；新信息或指标冲突先核对事实与公开边界，再改母版及尚未投递的衍生版本。

[一页通用版 TeX](WentworthLiu_General_DS_OnePage.tex) · [一页 PDF](WentworthLiu_General_DS_OnePage.pdf) 是为直接投递而裁剪的**衍生版**，项目名左侧、本人职责范围右侧的排版仅用于凸显具体贡献，不将项目主导混同于人员管理；不是制作新定制简历的内容起点。`resume.tex` 和 `resume_general_ds.tex` 是旧版留档，不能按文件名误认作当前母版。
