\textit{Data Scientist, Battery Intelligence Department}
\begin{itemize}
\item \textbf{Behavioural Risk Scoring \& MLOps.} Built an explainable risk-ranking system for rare thermal-runaway investigations, capturing 93\% of evaluated cases in the top-ranked 2\% of vehicles; the score ranks cases, not failure probabilities. Screened 1.5k+ features with Mann--Whitney tests and correlation controls, then delivered Docker-packaged batch scoring with data-quality gates, API publication, monitoring and case-driven refresh.
\item \textbf{Forecasting \& Cohort Decisions.} Combined propensity-score matching, ATT and dose-response analysis with recursive state-of-health forecasting to identify warranty-risk cohorts and evaluate battery-longevity interventions. Worked with BMS, performance and after-sales teams on staged OTA strategy evaluation; six-month matched-cohort and counterfactual analyses supported a \emph{projection} of tens of millions of RMB in avoided warranty costs for one model, not realised savings.
\item \textbf{Reusable Feature Engineering.} Built a department-wide offline Feature Store for 1.5k+ vehicle-cycle behaviour features, cutting feature-development time by approximately 85\%. Created a Git-managed YAML registry, schema-driven PySpark ETL, temporal alignment, validation, backfills and model-ready API exports, standardising features across analysis, training and scoring.
\item \textbf{NLP Classification \& Human Review.} Trained a Random Forest on domain-informed TF-IDF features for 50k+ after-sales work orders across 30+ categories. Routed low-confidence predictions to expert review and retrained on verified labels; automated over 93\% of labelled samples, raising accuracy from 83\% to 96\% in three months (weighted F1 $>0.90$).
\end{itemize}
