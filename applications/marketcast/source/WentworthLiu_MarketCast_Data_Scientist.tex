\textbf{Li Auto} \hfill \textit{Jul 2024 -- Present}\\
\textit{Data Scientist, Battery Intelligence Department}
\begin{itemize}
\item \textbf{Behavioural Risk Scoring \& MLOps.} Built an explainable relative-risk system to prioritise rare thermal-runaway investigations under extreme class imbalance. Captured 93\% of evaluated cases within the top-ranked 2\% of vehicles, narrowing investigation candidates from tens of thousands to thousands; the score ranks cases, not failure probabilities. Applied Mann--Whitney screening and correlation-cluster redundancy control to 1.5k+ vehicle-behaviour features, then developed decomposable, directional CDF-based scoring with platform-aware normalisation; productionised monthly Docker-packaged scoring with API delivery, validation, monitoring and case-driven refresh.
\item \textbf{Causal Inference \& Cohort-targeted Longevity Strategy.} Turned observational vehicle-behaviour data into cohort-targeted interventions by linking causal effect estimation, battery-degradation forecasting and OTA strategy evaluation. Used confounder control, propensity-score matching, ATT and dose-response estimation to isolate actionable drivers; recursively projected early-life battery state-of-health trajectories to identify warranty-risk cohorts. Partnered with BMS, cell-design, performance and after-sales teams to map feasible interventions and evaluate staged OTA rollout. Six-month matched-cohort and within-vehicle counterfactual evaluations supported a \emph{projection} of tens of millions of RMB in avoided warranty costs for a single vehicle model, not realised savings.
\item \textbf{End-to-End Offline Feature Store.} Designed 1.5k+ vehicle-cycle behaviour features and built an in-house, department-wide offline Feature Store, cutting feature-development time by approximately 85\% and reducing duplicated computation and storage. Implemented a Git-managed YAML feature registry with metadata and lineage, schema-driven PySpark ETL with temporal alignment, validated ingestion, historical backfills, monitoring and model-ready export through internal APIs, making features reproducible across analysis, training and batch scoring.
\item \textbf{Confidence-Aware NLP Work-Order Classification.} Built a confidence-aware system for 50k+ noisy after-sales work orders across 30+ categories, routing low-confidence cases to expert review. Automated over 93\% of labelled samples, raising accuracy from 83\% to 96\% in three months (weighted F1 $>0.90$) and replacing roughly 12 manual hours weekly. Co-designed the label taxonomy, evaluated expert terms using keyword-level F1, engineered domain-informed TF-IDF features and trained a Random Forest classifier with weekly retraining on verified labels.
\end{itemize}
