# 候选人事实与证据索引

## 来源层级

1. 用户原话及原始材料：`intake/linkedin_cv.md`（早期第一人称陈述，部分签证与部门表述已过期）；真正的项目原始记录若不在仓库内，必须标为待查。
2. 项目答复与带边界的证据：`../applications/fuse/02_candidate_evidence/` 的 `li_auto_project_answers.md`、`bytedance_project_answers.md`。其中也包含整理和推论，**不能把每句都当作独立核验的原始事实**。
3. `*_capability_evidence_map.md` 是派生的安全措辞建议，不应反向证明项目数字。
4. JD、简历、网站和 LinkedIn 是用途不同的表达，不因重复出现便变成新证据。
