本目录存放候选人原始陈述、项目答复及由它们整理的措辞边界；不是一份已全部核验的事实数据库。写简历时，先查相应项目答复和其中的本人确认，再对照 [LinkedIn 工作稿](../profile/linkedin/linkedin_profile.md) 和已投递简历。旧简历、JD、参考样本不能反过来证明项目数字。

## 新证据如何入库

新增本人确认或原始材料时，先在对应项目答复中记清主张、出处、确认日期、样本与分母、可公开粒度；再更新本清单。未经核实的推论留在项目答复里并明确标为推论，不直接抄进简历。已投递版本保持原样，新事实只用于后续草稿。
