# Maintenance Rules

## Purpose
Keep the website coherent as it evolves.

## Rules
1. The homepage stays curated, not exhaustive.
2. Resume remains the factual baseline.
3. New content must be assigned to a destination before writing:
   - homepage
   - project detail page
   - notes/blog
   - LinkedIn
   - resume
4. Motion must remain optional to understanding.
5. Do not re-open the product direction unless explicitly requested.
6. Keep tone aligned with the approved balance: thoughtful, international, lightly playful.
7. Avoid homepage bloat by limiting phase-1 projects to the selected core set.
8. Flag factual inconsistencies instead of silently rewriting them.
9. Preserve confidentiality-safe wording for Li Auto-related content.
10. Prefer refining existing docs over creating duplicate strategy documents.
