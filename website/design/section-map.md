# Section Map

## Purpose
Map each homepage section to its user question, content type, and cat role.

| Section | User Question Answered | Content Type | Cat Role |
|---|---|---|---|
| Hero / Start Here | Who is this person? | headline, subline, chips, CTAs | anchor presence |
| At a Glance | What does he do, and why should I care? | short summary blocks | light companion |
| Guided Entry | Where should I go next? | jump links / navigation cues | guide |
| Path & Traces | How did this profile develop? | linked timeline + trace panel | path follower |
| Selected Signals | What meaningful work has he done? | half-expanded project summaries | observer |
| How I Think | How does he approach problems and collaboration? | short thought blocks | margin companion |
| A Few Beliefs | What does he believe about good work? | concise statements | quiet accent |
| For Recruiters | Can I place this candidate quickly? | utility panel | minimal or none |
| Let’s Connect | What should I do if I’m interested? | closing CTA | subtle closing presence |

## Rule
Every section must justify itself through clarity, differentiation, trust, or memorability.
