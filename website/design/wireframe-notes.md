# Wireframe Notes

## Purpose
Capture layout planning before visual design and implementation.

## Required Coverage
- desktop homepage structure
- mobile homepage structure
- section spacing and pacing
- anchor/navigation behavior
- sticky vs non-sticky decisions
- recruiter utility visibility
- Path & Traces interaction behavior

## Priority Areas
1. Hero hierarchy
2. At a Glance readability
3. Guided Entry placement
4. Path & Traces left-right linkage
5. Selected Signals card behavior
6. Recruiter panel clarity on both desktop and mobile

## Rule
Validate wireframe logic before choosing the final implementation stack.
