- background: pale off-white / light cream
- typography: deep charcoal gray

This is a color inversion of the original dark reference.

### Central Graphic
Replace the original topographic contour visual with:
- a centered Siamese cat head

## Motion Recommendation

### Desired Effect
When the cursor approaches the cat glyph field:
- nearby glyphs shift slightly away from the cursor
- glyphs float with a subtle vertical looseness
- glyphs spring back to their home positions
- the overall cat head remains stable

### Motion Quality Rule
The cursor should "ruffle" the cat, not break the cat.

## Technical Recommendation
Best future implementation path:
- custom coded canvas-based hero component
- later embeddable in a coded site or Framer via custom code component

Preferred rendering choice:
- dot-matrix / ASCII hybrid

Why:
- easier to keep elegant
- easier to keep performant
- easier to preserve shape across screen sizes
