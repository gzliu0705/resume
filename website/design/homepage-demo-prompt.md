# Homepage Demo Prompt

Use this prompt when generating or mocking the hero visual.

---

Create a minimalist editorial homepage hero for a personal website.

Color transformation:
- invert the original dark style into a pale off-white / light cream background
- all text, lines, and graphics should be deep charcoal gray
- keep the palette restrained and premium

Main composition:
- preserve the overall layout structure of the reference homepage
- keep four small technical information cards along the top
- keep a large bold sans-serif anchor word in the lower-left
- keep a right-lower narrative text block
- optionally retain a very subtle grid background
- remove unnecessary topology labels and extra decorative tags

Core visual replacement:
- replace the original contour / terrain graphic with a centered Siamese cat head
- cat should be front-facing, only the head, no body
- both ears must be fully visible
- the cat should be constructed from dense English letters / ASCII-like character marks / dot-matrix glyphs
- the effect should look like a computational topography made from characters
- no old contour map lines should remain

Text replacements:
- large lower-left word: `GUANZHANGLIU`
- right-lower narrative title: `Interpreting complex systems with data.`
- supporting text: `I’m a data scientist at Li Auto’s Battery Intelligence department, working on applied machine learning, feature systems, and decision-focused analytics across real-world EV battery data. Previously at ByteDance. Trained in scientific computing. Currently open to London opportunities.`

Top cards:
1. CURRENT — Data Scientist, Li Auto
2. FOCUS — Battery Intelligence · Applied ML
3. BASED IN — Beijing · Open to London
4. LOOKING FOR — Data Scientist Roles

Style requirements:
- 2D flat
- editorial
- minimal data-visualization feel
- premium layout
- smart and observant mood
- professional first, playful second
- not childish

Interaction concept for future implementation:
- when the cursor approaches the cat letters, nearby letters should float and disperse slightly
- keep the cat silhouette readable and stable
