# Motion Notes

## Purpose
Define motion rules before implementation.

## Motion Principles
- motion should support reading, not distract from it
- motion should reward attention, not demand it
- motion must remain optional to understanding
- mobile behavior should stay simple and performant

## Recommended Motion Moments
- subtle section reveal on scroll
- timeline highlight changes in Path & Traces
- gentle cat movement or pose shifts between sections
- soft hover feedback on cards or navigation cues
- smooth anchor scrolling for Guided Entry links

## Avoid
- scroll hijacking
- long intro animations
- heavy parallax
- mascot-like continuous animation
- any motion that slows recruiter scanning

## Accessibility / Performance Reminder
If a motion effect does not improve orientation or hierarchy, remove it.
