# Personal Website Project — CLAUDE.md

## Project Purpose
This folder contains the planning and production materials for Guanzhang Liu’s personal website.

The website is a **creative, recruiter-friendly, editorial narrative resume** designed to support Guanzhang’s job search and personal positioning for **Data Scientist roles in London**.

This is not a generic portfolio and not a blog-first website. The website should create a strong personal identity while staying clear, internationally legible, and practically useful for recruiters and hiring managers.

## Current Phase
Phase 1 only.

Current goal:
- build the website documentation backbone
- create homepage content and structure
- define visual and interaction planning
- prepare for implementation

## Phase 1 Scope
Approved scope for phase 1:
- single long-form homepage
- English only
- no blog yet

- cat-led 2D flat visual identity

Reading model:

## Core Positioning
Approved positioning:

## Tone and Personality
The site should feel:
- thoughtful
- precise
- intellectually playful
- unconventional
- calm
- internationally legible

The site should avoid feeling:
- too academic
- too China-local
- too corporate
- too hype-driven
- too cute or childish

Professional / playful balance:
- 70% professional
- 30% playful

## Visual and Narrative Direction
Main visual/narrative object:
- a cat

The cat is not just decoration. It acts as:
- observer
- guide
- quiet narrative companion

Cat traits to preserve:
- observant
- smart
- curious

Visual direction:
- 2D flat
- editorial
- lightly playful
- clean and intentional

Do not turn the cat into:
- a childish mascot
- a cartoon gimmick
- a distracting animated toy
